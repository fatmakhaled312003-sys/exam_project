# صانع اختبارات القرآن الكريم

تطبيق Streamlit لتوليد أوراق اختبار القرآن الكريم، بمخرج نهائي ملف
**Word (.docx) قابل للتعديل بالكامل**، بترويسة وترقيم وأقسام ديناميكية،
ونموذجين كاملين في كل صفحة A4.

## التشغيل

```bash
pip install -r requirements.txt
streamlit run app.py
```

يفتح التطبيق في المتصفح تلقائياً (عادة على http://localhost:8501).

## بنية المشروع

```
exam/
├── app.py                          # التطبيق كاملاً (Streamlit + منطق التوليد + مُصدِّرا HTML/Word)
├── requirements.txt                # streamlit, python-docx
├── data/
│   └── quran-uthmani.txt           # نص القرآن الكريم الموثوق (Tanzil، عثماني) - المصدر الوحيد للنص
├── fonts/
│   └── README.md                   # تعليمات إضافة خط Amiri (اختياري، لمعاينة HTML فقط)
├── docs/
│   ├── QURAN_VALIDATION_REPORT.md  # تقرير التحقق من قاعدة بيانات القرآن
│   ├── TEST_REPORT.md              # تقرير الاختبارات المنفَّذة فعلياً
│   └── SOURCE_ATTRIBUTION.md       # مصدر وترخيص النص القرآني
└── README.md                       # هذا الملف
```

## كيف يعمل مصدر النص القرآني

`data/quran-uthmani.txt` هو المصدر الوحيد لنص الآيات (114 سورة، 6236
آية، نص Tanzil العثماني بدون أي تعديل). لا يُخزَّن أي نص قرآني مباشرة
داخل app.py: كل سؤال في قاعدة بيانات الأسئلة (`suwar_database` داخل
app.py) هو مجرد إحالة صغيرة (رقم السورة، رقم آية البداية، رقم آية
النهاية)، ويُجلب النص الفعلي من `data/quran-uthmani.txt` وقت توليد
الاختبار.

**لا تُعدِّلي `data/quran-uthmani.txt` يدوياً.** إن احتجت لاحقاً
تحديث السور/المدى المستخدَم في الأسئلة، عدّلي قاموس `suwar_database`
في `app.py` (أرقام آيات فقط، وليس نصاً).

## المتطلبات

- `streamlit` — واجهة التطبيق
- `python-docx` — توليد ملف Word

لا حاجة لأي مكتبة PDF أو خط إلزامي على الخادم؛ التطبيق يعمل بالكامل
بدون أي ملف خط في `fonts/` (ذلك المجلد اختياري تماماً، يُحسِّن شكل
معاينة HTML فقط إن أُضيف إليه خط Amiri - راجعي fonts/README.md).

## النشر (Deployment)

أي منصة تستضيف تطبيقات Streamlit (Streamlit Community Cloud، خادم
خاص، حاوية Docker...) تعمل مباشرة طالما:
1. تم تثبيت `requirements.txt`.
2. مجلد `data/` (وبداخله `quran-uthmani.txt`) موجود بجانب `app.py`
   بنفس المسار النسبي الموضّح أعلاه.

المسارات في الكود مبنية نسبياً لموقع `app.py` نفسه (`APP_DIR`)، وليس
لمجلد التشغيل الحالي، فتعمل بغض النظر عن كيفية إطلاق التطبيق.
