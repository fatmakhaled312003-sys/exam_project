# مجلد الخطوط (اختياري تماماً)

المخرج الأساسي للتطبيق هو ملف **Word (.docx)**، وهو **لا يحتاج** أي
ملف خط في هذا المجلد: يعتمد Word على الخطوط المثبّتة على جهاز
المستخدم (Arial لعموم النص، و"Traditional Arabic" تحديداً لنص الآيات
القرآنية - وهو مثبَّت افتراضياً مع أي نسخة من Microsoft Office تدعم
العربية).

هذا المجلد يُستخدم فقط لتحسين شكل **معاينة/طباعة HTML** داخل المتصفح
(اختياري تماماً):

1. نزّلي خط "Amiri" (المُفضَّل لعرض النص العثماني القرآني بدقة) من
   Google Fonts: https://fonts.google.com/specimen/Amiri
   (مرخّص بموجب SIL Open Font License الذي يسمح بإعادة التوزيع)
2. ضعي الملفين التاليين هنا:
   - Amiri-Regular.ttf
   - Amiri-Bold.ttf (اختياري)

**مهم:** لا تضعي هنا أي خط آخر غير Amiri أو Noto Naskh Arabic تحديداً.
التطبيق يتجاهل عمداً أي خط عام آخر (مثل DejaVu Sans أو Tahoma) عند
تضمين خط داخل صفحة المعاينة، لأن تغطيتها لرموز الرسم العثماني القرآني
الخاصة (كالألف الوصل ٱ) غير مكتملة، وتضمين خط ناقص التغطية قسراً يمنع
المتصفح من التراجع التلقائي لخط نظام آخر يملك الرمز الناقص - فتظهر
مربعات فارغة بدلاً من بعض الحروف. بدون Amiri/Noto هنا، يعتمد المتصفح
تلقائياً على خطوطه الخاصة (وهي غالباً أفضل تعاملاً مع هذا التراجع).

يمكن أيضاً تحديد مسار مجلد الخطوط عبر متغيّر البيئة:
    QURAN_EXAM_FONT_DIR=/path/to/fonts
